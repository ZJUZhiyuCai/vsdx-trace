## [2.0.0] - 2026-09-03

### Changed

- Renamed the project and skill from `high-fidelity-visio-reconstruction` to
  `vsdx-trace`.
- Reworked the README and added separate Simplified Chinese documentation.
- Added UI metadata for Agent Skills-compatible clients.
- Clarified cross-version PNG compression reproducibility.

### Added

- Community health files, issue forms, pull-request template, and support policy.
- Python test matrix, Ruff checks, CodeQL scanning, Dependabot, and automated
  release packaging.
- Standard MIT license detection and independent-project trademark notice.

## [1.1.0] - 2026-09-02

### Added

- Privacy-sanitized full skill package.
- Native VSDX builder, validator, renderer, image comparison, and privacy tools.
- Deterministic synthetic Gold Standard and behavioral evaluations.
