# Support

Use the right channel so questions remain discoverable and security reports stay
private.

- Usage questions and reconstruction advice: [GitHub Discussions](https://github.com/ZJUZhiyuCai/vsdx-trace/discussions)
- Reproducible bugs: [bug report](https://github.com/ZJUZhiyuCai/vsdx-trace/issues/new?template=bug_report.yml)
- Feature ideas: [feature request](https://github.com/ZJUZhiyuCai/vsdx-trace/issues/new?template=feature_request.yml)
- Vulnerabilities: follow [`SECURITY.md`](SECURITY.md)

Include operating system, Python version, dependency versions, the command that
failed, and a synthetic reproduction when asking for help. Do not upload private
source diagrams or confidential generated files.
